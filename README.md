# Home Energy & Carbon Manager

A responsive household dashboard based on the MyEMS energy-management project. This major-project demo includes sample household electricity, cost, solar, appliance, and carbon data.

## Open the demo

Open `Home-Energy-Carbon-Manager.html` in a browser. No install or backend is required.

## Demo features

- Energy consumption and solar generation charts with week, month, and year ranges.
- Estimated bill and household CO2e summary.
- Appliance usage breakdown with simulated on/off switches.
- An Appliances screen with sample power, monthly kWh, and carbon estimates.
- A fake appliance-pairing flow that adds a fictional demo device; it does not connect to real hardware.
- Editable tariff and grid emissions factor, saved in the browser.
- CSV report export.

## Important

All meter readings and appliance data are illustrative sample data. This page does not connect to a utility, real MyEMS API, Wi-Fi, smart-home account, or physical appliance. Carbon is estimated as electricity use in kWh multiplied by the selected grid factor in kg CO2e/kWh. Replace the sample values and document local tariff and emissions-factor sources for a live deployment.
