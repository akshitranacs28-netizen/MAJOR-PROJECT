Google Home setup requirements

Home APIs are available through native Android and iOS SDKs. The current deployed site is static HTML, so it cannot launch Google’s native permission flow or read devices by itself.

1
Start a native app

2
Set up OAuth and testers

Create the Google Cloud OAuth setup and complete the Home APIs permissions flow.

3
Build a secure data bridge
