This project uses sample household meter readings and device estimates. It does not connect to a utility account or control real appliances.

For a live deployment, connect the dashboard to MyEMS API meters, spaces, and carbon reports. See the README in the home-energy folder.

Carbon estimate = imported electricity × grid emissions factor. Solar self-consumption is not counted as grid electricity in this demo.
