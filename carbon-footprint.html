Understand the estimate

What your electricity means for carbon.

Carbon dioxide equivalent, or CO₂e, puts different greenhouse gases into one comparable unit. This demo estimates the emissions associated with household grid electricity use.

A simple calculation

Multiply electricity used during a period by the grid emissions factor selected for that location and period.

Sample electricity use642 kWh
×
Sample grid factor0.73 kg CO₂e/kWh
=
Estimated electricity emissions468.7 kg CO₂e

That rounds to about 469 kg CO₂e for the sample month. This is an example using the demo dashboard's default factor, not a verified reading for your location.

What this estimate includes

01 / INPUT

Electricity for the period

Use measured grid electricity in kWh for the same dates as the report. The dashboard's sample household currently shows 642 kWh for a month.

02 / FACTOR

Regional grid emissions

The factor represents estimated emissions per unit of electricity. It can vary by region, time period, and the source used. Replace the demo factor with a documented local value for a real study.

03 / SCOPE

Electricity only

This estimate does not include transport, cooking gas, food, or purchased goods. Solar generation is displayed separately in this demo and is not subtracted from the grid-use estimate.

Use the number carefully

01 · Measure

Choose a real meter reading

Demo values help explore the interface. For reporting, use the meter data for the correct home and dates.

02 · Document

Record the factor

Write down the factor's source, region, units, and year so another person can reproduce the estimate.

03 · Compare

Keep periods consistent

Compare similar dates and meter boundaries. A change in occupants or weather can affect energy use.
